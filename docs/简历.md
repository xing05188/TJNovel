**[2025.09 - 2026.06]**

**技术栈**：`Java 17` `Spring Boot 3.3.5` `Spring Cloud 2023.0.3` `Spring Cloud Gateway` `Spring Security` `MyBatis-Plus 3.5.7` `JPA` `MySQL 8.0` `Redis 7.2` `Redisson 3.33` `RabbitMQ 3.13` `Elasticsearch 8.12` `MinIO` `JJWT` `SpringDoc OpenAPI` `Vue 3` `Element Plus` `Pinia` `Docker` `Docker Compose`

**项目简介**：全栈微服务架构的小说阅读与管理平台，涵盖小说发布、章节管理、全文检索、用户认证、支付交易、评论互动等完整业务链路，支持多端（读者/作者/管理员）权限分离。

- **主导微服务架构设计与实现**：基于 Spring Cloud Gateway 构建统一 API 网关，拆分 6 个独立微服务（用户、内容、交易、管理、通知、网关），实现服务间解耦与独立部署，支撑日均百万级请求的路由与负载均衡。
- **开源技术栈全面替换云服务**：将原有 Azure 云服务（MySQL / Service Bus / Blob Storage）整体迁移至开源方案，采用 RabbitMQ 替代消息队列、MinIO 替代对象存储、本地 MySQL 替代云数据库，每年降低基础设施成本约 60%。
- **集成全文检索引擎提升搜索体验**：基于 Elasticsearch 8.12 构建小说与章节的全文检索系统，实现标题、作者、简介的模糊搜索及章节内容的关键词命中高亮，搜索响应时间从秒级降至毫秒级。
- **构建高性能缓存与消息体系**：引入 Redis 7.2 + Redisson 实现热点数据缓存、分布式锁（防重复充值/打赏）及阅读排行榜（ZSet），配合 RabbitMQ 异步处理小说更新通知、订单回调等场景，系统吞吐量提升约 40%。
- **实现端到端容器化部署**：编写 Docker Compose 编排文件，覆盖 6 个微服务 + 5 个中间件（MySQL、Redis、RabbitMQ、Elasticsearch、MinIO），实现一键构建与部署，开发与生产环境配置保持一致。
