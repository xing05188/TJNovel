:::
**[2026.03 - 2026.06]**

**技术栈**：`Java` `Spring Boot` `Vue 3` `MySQL` `Redis` `RocketMQ` `MinIO` `Qdrant` `LangChain4j` `DeepSeek` `FFmpeg` `Tesseract OCR`
**项目简介**：Video Agent 平台，将长视频转化为可检索、可追溯、可追问的结构化知识。融合 ASR 与关键帧 OCR 构建多模态时序上下文，通过 Planner-Executor-Critic 多轮编排完成用户分析目标。
- **设计多模态 VideoContext 流水线**：FFmpeg 按 60s 切分音频，场景变化检测抽取关键帧，30s 保底采样防遗漏静态板书；ASR 与 OCR 线程池并行，感知哈希去重，单路失败时保留另一路信息，保障多模态解析鲁棒性。
- **构建受控 AgentLoop 编排器**：Planner 拆解目标为子任务，Executor 生成结构与证据，Critic 校验覆盖完整性与可靠性；未通过时定向补充检索，最多两轮收敛，平衡修正能力与 Token 成本。

- **设计高并发异步任务链路**：5MB 分片上传，Redis 追踪进度，MinIO 合并；RocketMQ 异步削峰，Redisson 内容指纹消费幂等；用户级与全局令牌桶双重限流，ASR 及模型调用指数退避重试，保障高负载稳定性。
